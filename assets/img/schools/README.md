# School crests shipped with the site

Put a school's crest here as `<ministry code>.webp` (or `.png`, `.jpg`, `.svg`), about 256 px square, for example `01037.webp` for Kingston College.
Then point the school at it in Supabase. See [supabase/import/README.md](../../../supabase/import/README.md#adding-a-schools-crest).

[SOURCES.md](SOURCES.md) lists where each crest came from.
