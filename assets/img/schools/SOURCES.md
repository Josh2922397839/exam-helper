# Where each school crest came from

Crests are shown only to identify each school in leagues and on profiles. Each one was checked by eye, trimmed, centred and saved as a 256 px WebP. If a school would like its crest changed or removed, update or delete the file and set `logo` in `public.schools` (see [supabase/import/README.md](../../../supabase/import/README.md#adding-a-schools-crest)); the site then shows a generated crest instead.
